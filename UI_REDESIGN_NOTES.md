# Yuyu UI refresh

This update refreshes presentation only. Existing API calls, models, app state, fetching flow, and action callbacks are retained.

## Updated screens and components
- Hero discovery cards: staggered reveal animation and elevated surfaces.
- Hero details: cinematic image header, overview panel, base-stat pills, skill section, skin collection cards, and skin-to-skin preview cards.
- Cosmetic library: category-aware header for Newly Added, Emotes, Trails, Recalls, Eliminations, and Respawns; animated category transitions and staggered item cards.
- Saved collection: collection summary, animated list entries, and updated empty state.
- Restore: animated environment and maintenance cards.
- Settings and info: control-center header and refreshed preference, history, and about panels.
- Operation banner: animated status icon and smoothed progress changes.
- Shared premium UI components: gradient panels, section headings, stat pills, reveal transitions, and empty states.

No fetching endpoints or state-management methods were intentionally changed.
